# AuthorOps-Skills

Portable, agent-native skills for serious writing, research, editing, citations, manuscripts, books, academic work, and publication-quality review.

AuthorOps-Skills is the **skill layer only**. It provides independently invocable `SKILL.md` units with a common contract so agents can discover, invoke, compose, test, and improve them. Workflow orchestration and application-specific pipelines belong outside this repository.

## Core principle

> Skills are reusable intellectual operations, not end-to-end pipelines.

The library is intentionally empirical: it grows through real use, observed failure modes, evaluation, and disciplined revision.

## Domains

- writing
- editing
- transformation
- research
- citations
- academic
- manuscripts
- books
- publishing
- quality
- forensics
