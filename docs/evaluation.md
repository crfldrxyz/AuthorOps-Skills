# Skill Evaluation

A skill is ready for broad use when it produces useful, bounded, repeatable judgments on representative inputs.

## Evaluation dimensions
- **Correctness:** findings match the supplied evidence.
- **Completeness:** material failure modes are covered for the declared scope.
- **Calibration:** confidence and severity reflect uncertainty.
- **Safety:** no fabricated evidence, sources, quotations, or verification.
- **Agency:** rewrites preserve author intent and are separated from findings.
- **Composability:** outputs can be consumed by another agent or skill.

## Regression practice
When a real use reveals a failure, preserve a minimal fixture and add the failure mode to the skill's quality gates. Prefer targeted fixes over broad prompt expansion.
