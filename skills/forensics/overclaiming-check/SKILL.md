# Overclaiming Check

Compare claim strength with evidence strength. Inspect certainty markers, causal language, generalization scope, temporal claims, population claims, and implied mechanisms.

Flag only defensible mismatches and explain how to calibrate language without weakening a legitimately supported conclusion.
