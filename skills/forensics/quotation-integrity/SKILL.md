# Quotation Integrity

Compare each quotation against the supplied source text when available. Check exact wording, omissions, bracketed changes, ellipses, speaker attribution, context, and citation location. Mark unverifiable quotations when the source is unavailable.

Quality gates: no fabricated quote verification.
