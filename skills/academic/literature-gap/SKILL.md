# Literature Gap

Classify gaps as conceptual, empirical, methodological, contextual, theoretical, measurement, or synthesis gaps. Require evidence from the supplied literature for each gap claim. Distinguish "not studied" from "not found in this search."

Quality gates: bounded claims and transparent search limitations.
