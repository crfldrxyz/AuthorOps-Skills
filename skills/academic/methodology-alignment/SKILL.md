# Methodology Alignment

Trace the chain: research question → design → sampling/data → measures → analysis → inference. Identify mismatches, missing methodological justification, invalid inference, and conclusions that exceed the design.

Do not substitute discipline-specific expert judgment with generic methodological rules. Mark areas requiring domain review.
