# Skills

This directory contains the canonical AuthorOps skill library.

## Domain rules

Each skill lives at:

`skills/<domain>/<skill-name>/SKILL.md`

A skill must represent one reusable intellectual operation. Skills are independently invocable and must not encode an end-to-end workflow.

## Domains

| Domain | Primary responsibility |
| --- | --- |
| writing | ideation, outlines, arguments, titles, introductions, conclusions |
| editing | sentence and paragraph quality, grammar, clarity, consistency |
| transformation | paraphrasing, simplification, compression, expansion, voice |
| research | questions, sources, evidence, methods, bias, verification |
| citations | generation, style, completeness, mapping, accuracy |
| academic | paper-specific scholarly review and response |
| manuscripts | long-form structure, consistency, readiness |
| books | book architecture and narrative continuity |
| publishing | venue fit, requirements, peer review, disclosures |
| quality | reasoning, contradiction, assumptions, overclaiming, completeness |
| forensics | attribution, provenance, quotation integrity, plagiarism risk |

Keep new skills in the narrowest domain that reflects their primary responsibility. Do not duplicate a skill merely to make it discoverable from multiple domains; use the registry and related-skill references instead.
