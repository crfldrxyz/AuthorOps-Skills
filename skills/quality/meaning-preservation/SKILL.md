# Meaning Preservation

Extract the source proposition, qualifiers, actors, relationships, quantities, temporal scope, certainty, and limitations. Compare each against the transformed version.

Flag additions, omissions, strengthened or weakened claims, altered causality, changed attribution, and lost uncertainty.

Return a structured semantic-diff report with confidence.
