# Consistency Check

Extract document entities, definitions, quantities, dates, claims, and terminology. Compare repeated references across the document.

Flag contradictions and meaningful drift. Distinguish true contradictions from contextual changes or intentional qualification.

Return paired locations, conflict description, severity, and resolution options.
