# Argument Check

Reconstruct the argument before judging it. Identify major claims, supporting premises, evidence, implicit assumptions, inferential links, counterevidence, and conclusions.

Flag unsupported premises, non sequiturs, overreach, circular reasoning, false dichotomies, missing alternatives, and conclusions stronger than their evidence.

Report reasoning gaps without rewriting the author's position into a different argument.
