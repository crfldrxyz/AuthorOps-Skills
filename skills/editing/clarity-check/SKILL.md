# Clarity Check

## Procedure
1. Determine the intended proposition or action in each passage.
2. Identify ambiguous referents, overloaded terms, hidden assumptions, excessive nesting, abstraction jumps, and unclear relationships.
3. Prefer diagnosis before rewriting.
4. Offer the smallest revision that materially improves comprehension.

## Output
Report location, clarity problem, why it impedes understanding, suggested action, optional rewrite, and confidence.

## Quality Gate
Never simplify away necessary technical precision.
