# Key Contribution

State the contribution precisely: empirical finding, method, theory, synthesis, dataset, interpretation, or application. Compare it with cited prior work and flag novelty claims not supported by the supplied literature.

Quality gates: distinguish contribution from topic, result, and marketing language.
