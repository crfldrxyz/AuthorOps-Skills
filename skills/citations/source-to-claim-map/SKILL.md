# Source-to-Claim Map

Extract atomic substantive claims and link each to one or more supporting sources when those sources are available. Record support type: direct, indirect, contextual, contradictory, or absent.

Never infer support merely because a citation appears nearby. Preserve source boundaries and identify claims that require human verification.

Return a structured mapping suitable for downstream citation and evidence audits.
